# Verificação de auto-merge para `dev`

Este arquivo é uma alteração documental inofensiva criada para verificar o fluxo de pull requests com destino à `dev`.

Critério: a automação deve habilitar o auto-merge e o GitHub deve integrar a PR somente após satisfazer as verificações e regras aplicáveis.

A branch `main` permanece sujeita a aprovação humana.
